Conectando a base tbContatos ao Power BI

Transforme esta base de e-mails em dashboards executivos no Power BI de forma fácil e rápida.

01

Exportar Base

Vá na aba "Base de Dados" e clique em "Baixar CSV" para obter os dados mais atualizados em formato tabular estruturado.

02

Importar Dados

Abra o Power BI Desktop, vá em Obter Dados > Texto/CSV, escolha o arquivo baixado e certifique-se de usar a codificação UTF-8.

03

Estruturar Modelo

Garanta as tipagens de texto corretas nas colunas de Concessão, Área, Função e Status no painel do Power Query.

Principais Fórmulas DAX Recomendadas

// Medida para Contagem de Contatos Ativos Contatos Ativos = CALCULATE(COUNTA('tbContatos'[ID]), 'tbContatos'[Status] = "Ativo")
// Medida para Cobertura de E-mails Emails Cadastrados = CALCULATE(COUNTA('tbContatos'[E-mail]), NOT(ISBLANK('tbContatos'[E-mail])))

Deploy no Vercel Recomendado

Este projeto inclui vercel.json e package.json pré-configurados. Qualquer alteração no seu GitHub atualiza o Vercel automaticamente.

  1. Acesse vercel.com/new
  2. Importe o repositório KassiusPrime/Inov
  3. Clique em Deploy (sem precisar alterar nenhuma configuração)
Conectar no Vercel
Emular via GitHub Pages Gratuito

Você também pode ativar a emulação web nativa gratuita do próprio GitHub em 2 cliques:

  1. No GitHub, abra Settings do repositório Inov
  2. No menu lateral, clique em Pages
  3. Em Branch, selecione main / / (root) e clique em Save
